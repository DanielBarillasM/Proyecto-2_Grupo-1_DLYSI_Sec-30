# Tema visual - Veilstone

Tema derivado de **Midnight Galaxy** de Theme Factory y adaptado al brief de Eryndor.

## Paleta

| Uso | Color | Hex |
|---|---|---|
| Fondo profundo | Obsidiana | `#171A24` |
| Superficie | Púrpura profundo | `#2B1E3E` |
| Jerarquía secundaria | Azul cósmico | `#4A4E8F` |
| Magia principal | Cian mineral | `#4FC3C8` |
| Hallazgo / advertencia | Oro brasa | `#D6A34A` |
| Texto claro | Plata | `#E6E6FA` |
| Texto secundario | Lavanda | `#A490C2` |
| Éxito | Musgo claro | `#79A879` |

## Tipografía

- Encabezados: FreeSans Bold o, en entornos sin esa fuente, `Segoe UI`/sans-serif en peso 700.
- Cuerpo: FreeSans o `Segoe UI`.
- Código y datos: `Cascadia Code`, `Consolas` o monospace.

## Reglas

- Las figuras técnicas usan fondo claro para conservar legibilidad y exportación.
- El fondo oscuro se reserva para portadas, separadores y diapositivas narrativas.
- El cian identifica el generador y el oro identifica el discriminador.
- El rojo solo señala fallos, colapso o evidencia dudosa.
- No se agregan texturas detrás de curvas, tablas o vecinos cercanos.
- Toda figura debe seguir siendo comprensible en escala de grises mediante estilos de línea y etiquetas.
